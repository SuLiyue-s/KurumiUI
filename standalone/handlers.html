独立渲染 handlers JSON 只存函数名与入参 · 实现放在各组件 handlers.js

JSON 不能写函数，于是我们让 JSON 只写「函数名 + 入参」

本页所有按钮的动作都来自 config/demos/handlers.json，文件里没有任何 JS。 例如：{ "fn": "toast.success", "args": { "text": "保存成功" } }； 也支持动作数组 { "actions": [ … ] }、动作与函数混写、以及 { "action": "handlers.run", "params": { "fn": "...", "args": {} } }。 函数实现分散在 src/components/handlers/*.handlers.js，按组件拆开，可按需加载。
