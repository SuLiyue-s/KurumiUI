保活规则（验收重点）

pane 与 iframe 创建后永不重建；切换标签只切 hidden/.is-active，首次激活才设置 src。在 pages/profile.html 改输入值后切走再切回，值仍在。

可配置 props

  • home：固定首页，pinned:true 不可关闭
  • initial：启动时额外打开的标签数组（第一个激活）
  • keepAlive / maxTabs / closable / contextMenu / drag

实例 API

  • open(tab) / close(id) / closeOthers(id) / closeAll()
  • activate(id) / refresh(id) / getActive() / getTabs()
  • setTitle / setIcon / setBadge / setDirty
