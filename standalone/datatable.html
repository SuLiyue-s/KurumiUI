datatable 数据表格 v1.4.0 新组件 筛选 / 单选行 / 复选行 / 全选 / 排序 / 每页条数 / 分页 / 行高亮 / 导出 / 列设置

① 一体化配置：搜索 + 列筛选 + 多选行 + 排序 + 分页 + 工具栏动作

整个表格由下面这段 JSON 渲染（KUI.renderNode）

所有能力都由 config JSON 决定：search / filter / selection / sort / pagination / toolbar.actions / export / columnsToggle / densityToggle。 行点击高亮、↑↓ 移动、空格选择、Enter 触发 rowClickAction。 


    

    

      
      
      
      
      
    

  


  
  

    

      
② 单选行（radio）+ 行内动作列 + 行点击高亮

    

    

      selection.mode = "single"：单选行；columns[{ type:"actions", buttons:[...] }]：行内动作列，
      按钮的 action 走同一套动作系统（这里用 toast）；rowHighlight 控制行点击高亮。
    

    

    

      
      
    

  


  
  

    

      
③ 多选 + 跨页保留 + 每页条数 / 跳页（200 行数据）

    

    

      表头复选框支持全选当前页（selectAllScope 可改 all）；selection.keepAcrossPages 控制切页是否保留选择；
      分页区可切换每页条数、输入页码跳页。
    

    

  


  
  

    

      
④ 轻量模式：关闭筛选/工具栏，仅保留排序与分页

    

    

      表格是独立组件，可单独挂载：KUI.datatable.create(host, props)，也可用 KUI.renderNode({ type:'datatable', props })。
      不加载 src/components/datatable.js 时，该类型会渲染成「未知类型占位块」，其余组件完全不受影响（可拆卸）。

⑥ 配置速查（props）

    

    

      

        columns列定义：key/title/width/align/sortable/filter/format/dict/hidden
        data / rows数据源（数组）
        rowKey行标识字段，默认 id
        search{ enabled, placeholder, width, keys }
        filter{ enabled, columns, clearable }；列级 filter.type = text|select|range
      

      

        selection{ mode:none|single|multi, showSelectAll, selectOnRowClick, keepAcrossPages, selectAllScope }
        sort{ enabled, mode:single|multi, default:[{key,order}] }
        pagination{ enabled, pageSize, pageSizes, showTotal, showSizer, showJumper }
        toolbar{ enabled, title, subtitle, actions:[{label,icon,action,variant}] }
        其它bordered / striped / hoverable / compact / height / rowHighlight / rowClickAction / columnsToggle / densityToggle / refresh / export / text / on
