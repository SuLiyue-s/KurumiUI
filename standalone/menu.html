这个页面演示什么

menu 组件只吃一个 JSON 节点：分组 group、菜单项 item 与 divider；二级菜单 = item 自带 children。点击菜单项时组件处理 item.target：{tab} 开标签、{action} 走动作、{menu} 切选中。

可配置 props（节选）

  • brand / collapsible / width / collapsedWidth
  • items / footer / accordion / flyout
  • defaultActive / collapsed / tooltip

实例 API（通过 __kuiInstance 拿到）

  • setActive(id) / getActive()
  • toggle() / setCollapsed(bool) / expand()
  • setBadge(id, value) / setItems(items)
