弹窗剧场

本页所有弹窗都通过 KUI.frame.dialog.* 转发给主框架渲染（业务 iframe 内不建遮罩层），Promise 结果回传本页。

5 种方法 Promise 回传 弹窗内嵌套
验证点：① 每个按钮都会在主框架上弹出对应弹窗并返回 Promise 结果（本页「最近结果」会显示）；② 「连续两层」先 confirm 再立刻 form，验证弹窗队列；③ 「弹窗内再开一层」在 custom 弹窗里放一个按钮，点击后由 dialog-frame 内部再发一次确认框；④ 关闭弹窗后主框架焦点正确回到页面。

alert · 通告

KUI.frame.dialog.alert(cfg) → Promise<void>

信息 / 警告 / 错误三种 type，支持 danger 红色确认按钮。

confirm · 确认

KUI.frame.dialog.confirm(cfg) → Promise<boolean>

确定返回 true，取消返回 false；danger 按钮组用于破坏性操作。

prompt · 输入

KUI.frame.dialog.prompt(cfg) → Promise<string|null>

单行 / 多行输入，带 required 与长度规则。

form · 表单弹窗

KUI.frame.dialog.form(cfg) → Promise<object|null>

nodes + data + layout，提交后 resolve 出整份数据。

custom · 自定义

KUI.frame.dialog.custom(cfg) → Promise<any>

nodes 自定义内容 + actions 自定义按钮（close / resolve / false）。

连续两层

confirm().then(ok => form())

先确认再填写，验证弹窗关闭/打开顺序与 Promise 链。
