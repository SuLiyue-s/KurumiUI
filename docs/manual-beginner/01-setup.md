# 01 · 准备环境

> 适用版本：KurumiUI v1.4.0 ｜ 难度：⭐ 入门 ｜ 前置章节：无 ｜ 阅读时长：约 25 分钟

## 本章目标

- 认识 5 个最基础的概念：文件、文件夹、路径、扩展名、编辑器。
- 知道「命令行」是什么，会打开它，会用 `cd`、`dir` / `ls` 在两个文件夹之间走动。
- 在自己的电脑上装好 Node.js，并能用 `node -v`、`npm -v` 验证安装成功。
- （可选）装好 VS Code 和 Git，为后面改配置、下载项目做好准备。
- 完成 3 道小练习，达到「可以开始读第 02 章」的状态。

> 这一章**不碰 KurumiUI 项目**，只准备电脑环境。全程大约 20~25 分钟，其中下载安装 Node.js 可能需要 5~10 分钟。做完后请直接进入 [02-first-run.md](02-first-run.md)。

## 1. 五个基础词，看懂就够用

后面每一章都会用到这 5 个词。它们不难，只要混个脸熟即可，不用背。

### 1.1 文件与文件夹

- **文件**：电脑里保存内容的最小单位。一张图片、一段文字、一个网页，都是文件。
- **文件夹（目录）**：用来装文件的盒子。文件夹里可以再放文件夹，就像抽屉里套小抽屉。

KurumiUI 本身就是一个**文件夹**：下载或克隆后会得到一个叫 `KurumiUI` 的文件夹，里面装着这个项目的所有文件。

### 1.2 路径

**路径（path）**：从「某个位置」走到一个文件（或文件夹）的路线，例如：

```text
config/app.json
```

这表示「在项目文件夹里的 `config` 文件夹里，有一个叫 `app.json` 的文件」。本手册里的路径一律写成这种**从项目文件夹开始**的写法，你只要知道它是「哪个文件夹里的哪个文件」就够了。

> 小提示：路径里出现空格或中文时，在命令行里要加上英文双引号，例如 `cd "我的 项目"`。

### 1.3 扩展名

**扩展名**：文件名最后一个英文句点后面的部分，用来告诉电脑「这是什么类型的文件」。本手册最常见的是这三种：

| 扩展名 | 是什么 | 例子 |
| --- | --- | --- |
| `.html` | 网页文件，双击会用浏览器打开 | `index.html` |
| `.json` | 配置文件，用文字描述「界面长什么样」 | `config/app.json` |
| `.js` | 脚本文件，负责让页面动起来，或让本地服务器工作 | `server.js` |

> Windows 默认可能隐藏扩展名。建议打开文件资源管理器，在「查看」里勾选「文件扩展名」，这样你能一眼看出 `app.json` 是配置文件，而不是被系统藏起来。

### 1.4 编辑器

**编辑器**：用来打开、修改文本文件的软件。Windows 自带的「记事本」、macOS 的「文本编辑」都算编辑器，但它们不太适合改配置文件：容易存错编码、看不出括号配对。

本手册推荐 **Visual Studio Code（简称 VS Code）**，免费、跨平台、对 JSON 友好。它是**可选**的：不装也能跟着做，但装了会舒服很多，第 4 节会讲怎么装。

## 2. 命令行：一个用文字下命令的窗口

### 2.1 它是什么

**命令行（终端）**：一个用文字输入命令的窗口。你输入一行字、按回车，电脑执行，然后把结果显示在下面。它和「双击图标」做的是同一件事，只是用打字代替鼠标。

后面启动项目、安装依赖、生成配置，都要在这个窗口里输入一两行命令。

### 2.2 怎么打开它

| 系统 | 打开方式 | 你会看到 |
| --- | --- | --- |
| Windows | 点开始菜单，搜索 `PowerShell`，点「Windows PowerShell」 | 一个蓝底或黑底窗口，光标前有几行文字，例如 `PS>` |
| macOS | 按 `Command + 空格`，输入「终端」或 `Terminal`，按回车 | 一个白底或黑底窗口，光标前有 `$` 或 `%` 符号 |

> 本章统一用「命令行」称呼它，Windows 上就是 **PowerShell**，macOS 上就是 **终端**。两个系统输入的命令基本一样，只有下面这一处区别：列文件 Windows 用 `dir`，macOS 用 `ls`。

### 2.3 三个最常用的小命令

先学会这三个，就足够完成本章和下一章。

**① 看当前在哪个文件夹**

```bash
# Windows 与 macOS 都可以
pwd
```

> 你会看到：一行文件夹路径，说明你「站」在哪个文件夹里。刚打开的命令行通常站在你的用户文件夹（Windows 是用户目录，macOS 是用户的主目录）。

**② 看这个文件夹里有什么**

```bash
# Windows
dir
```

```bash
# macOS
ls
```

> 你会看到：一串文件名和文件夹名。这就是当前文件夹的内容。

**③ 进入一个文件夹 / 退回上一级**

```bash
# 进入名叫 KurumiUI 的文件夹（示例）
cd KurumiUI

# 退回上一级文件夹
cd ..
```

> 你会看到：命令提示符前面的文字变了，说明你进入了新的文件夹。输入 `cd` 时可以先打文件夹名的前几个字母，再按 **Tab 键**，系统会自动补全名字，不容易打错。

> 常见坑：`cd` 后面跟的文件夹名如果打错一个字母，会提示「找不到路径」。遇到这种情况不用慌，先 `dir` / `ls` 看清楚名字，再重新输入。

## 3. 安装 Node.js（本章最重要的一步）

### 3.1 Node.js 和 npm 是什么

- **Node.js**：一个能在你电脑上直接运行 JavaScript 的程序。KurumiUI 自带的本地小服务器（`server.js`）就是用它跑的。
- **npm**：安装 Node.js 时**顺带装好**的「包管理工具」，用来执行项目里的命令，例如 `npm start`、`npm run build:config`。你**不需要**单独安装它。

KurumiUI 对 Node.js 版本的要求写在了项目说明文件 `package.json` 里：**`>= 13.14.0`**，也就是 13.14.0 或更新的版本都可以。对新手，直接装 Node.js 官网首页推荐的 **LTS（长期支持版）** 最省心，版本号一般会比 13.14.0 高很多。

### 3.2 下载与安装

1. 打开浏览器，访问 Node.js 官网：<https://nodejs.org/> 。
2. 页面会自动识别你的系统，给你两个下载按钮。选标有 **LTS** 的那个（另一个是 Current，尝鲜版，新手不用）。
3. 下载完成后双击安装包：
   - Windows：文件名以 `.msi` 结尾，一路点「Next」，最后点「Install」，中途不需要改任何选项。
   - macOS：文件名以 `.pkg` 结尾，双击后一路点「继续」，最后点「安装」；如果系统提示「无法验证开发者」，到「系统设置 → 隐私与安全性」里点「仍要打开」。
4. 安装完成后，**关掉之前打开的命令行窗口，重新打开一个新的**（这一步很重要，不重开可能找不到命令）。

### 3.3 验证安装成功

在新打开的命令行里，依次输入下面两行（每行按一次回车）：

```bash
node -v
```

```bash
npm -v
```

> 你会看到类似这样的两行结果（版本号不一定相同，比 13.14.0 大就行）：
>
> ```text
> v20.11.1
> 10.2.4
> ```
>
> 第一行是 Node.js 的版本，第二行是 npm 的版本。只要两行都能显示出版本号，就说明安装成功，可以继续。

如果 `node -v` 显示的不是版本号而是报错，先看本章第 6 节「常见安装问题」。

### 3.4 装完自检清单

把下面几项逐个打勾，全部打勾就可以进入下一章：

- [ ] 命令行能打开，并且我知道 Windows 用 PowerShell、macOS 用「终端」。
- [ ] `node -v` 输出的版本号是 `v13.14.0` 或更高。
- [ ] `npm -v` 能输出版本号。
- [ ] 我会用 `cd 文件夹名` 进入文件夹、用 `cd ..` 退回上一级。
- [ ] 我会用 `dir`（Windows）或 `ls`（macOS）查看当前文件夹的内容。
- [ ] （可选）VS Code 已装好，能打开一个文件夹。
- [ ] （可选）`git --version` 能输出版本号。

## 4. 两个可选工具：VS Code 与 Git

这两个都**不是必须**的，但强烈建议至少装 VS Code。不装也能跟着本手册做，只是改文件时没那么方便。

### 4.1 VS Code：改文件用的编辑器（推荐）

1. 打开 <https://code.visualstudio.com/> ，点页面上的 **Download**，按系统下载安装包。
2. 安装时保持默认选项，完成后打开 VS Code。
3. 用它打开项目文件夹的方法：菜单 **文件 → 打开文件夹**，选中 KurumiUI 文件夹。
4. 你会看到：左侧是文件列表，点 `config/app.json` 就能在右侧看到内容，带行号、语法配色，方便找错。

> 为什么推荐它：改 JSON 时括号不配对会立刻显示错误颜色；保存时默认使用 UTF-8 编码，不会把中文存成乱码；还能直接看到文件路径，减少「改错文件」的概率。

### 4.2 Git：下载项目用的工具（可选）

Git 是一个「版本管理工具」。本手册里它只在一个地方用到：第 02 章用 `git clone` 把项目下载到电脑上。

- 如果你不想装 Git：完全没问题。第 02 章会教你另一种方式——在网页上点「Download ZIP」直接下载压缩包，效果一样。
- 如果你想装：打开 <https://git-scm.com/downloads> ，下载对应系统的安装包，一路默认安装。装完重新打开命令行，输入：

```bash
git --version
```

> 你会看到类似 `git version 2.43.0` 的一行字，说明装好了。

## 5. 提前看一眼：配置文件长什么样（可选）

第 02 章会带你把项目跑起来，并修改第一个配置。这里先花 1 分钟看看配置文件长什么样，到时候不会陌生。

KurumiUI 的界面主要由 `config/app.json` 这个文件描述。它里面的内容长这样（这是一小段节选）：

```json
{
  "app": {
    "title": "刻刻帝终端",
    "subtitle": "灵装回路 · 时间结界控制台"
  }
}
```

读法很简单：

- 外面一层 `{ }` 表示「一个对象」；
- `"app"` 是一个名字，冒号后面又是 `{ }`，表示「app 这个分组里有一些设置」；
- `"title": "刻刻帝终端"` 表示「标题」这个设置的值是「刻刻帝终端」；
- 名字和值都用**英文双引号**包起来，两组设置之间用**英文逗号**隔开；
- JSON 里**不能写注释**，也不能在最后一项后面多写逗号。

> 现在不用学会写 JSON，只要记住：**这个文件里的文字，决定了界面上显示什么**。第 02 章我们就改这里的标题。

## 6. 常见安装问题

| 现象 | 最可能的原因 | 先做这三步检查 | 修复 |
| --- | --- | --- | --- |
| 输入 `node -v` 提示「不是内部或外部命令」 | Node.js 没装成功，或装完没有重新打开命令行 | ① 确认安装包确实装完了 ② 关掉命令行重新打开 ③ 再输入一次 `node -v` | 重新运行安装包，保持默认选项装完；仍不行就重启电脑再试 |
| 浏览器下载 Node.js 安装包很慢或失败 | 网络原因 | ① 换一个网络 ② 换成官网的其它下载入口 ③ 稍后再试 | 可从国内镜像站（如 npmmirror.com 的 node 镜像）下载同版本安装包，装完同样用 `node -v` 验证 |
| 安装时提示权限不足、无法写入 | 没有管理员权限，或被安全软件拦截 | ① 确认用的是自己的电脑 ② 关闭拦截弹窗 ③ 重新双击安装包 | Windows 右键安装包选「以管理员身份运行」；macOS 到「隐私与安全性」里允许 |
| macOS 提示「无法打开，因为无法验证开发者」 | 系统安全策略拦截了安装包 | ① 打开「系统设置 → 隐私与安全性」 ② 看页面下方是否有「仍要打开」 ③ 点它并确认 | 允许后重新双击安装包，按提示继续 |
| `node -v` 显示的版本比 `v13.14.0` 低 | 电脑上装过很旧的 Node.js | ① 记下当前版本 ② 去官网下载最新 LTS ③ 覆盖安装 | 覆盖安装新版后重开命令行，再确认版本号 |
| 命令里的文件夹名有空格，提示找不到路径 | 路径没有加引号，被当成了两段 | ① 看文件夹名里是否有空格 ② 给路径加上英文双引号 ③ 再执行 | 写成 `cd "我的 项目"` 这种形式 |
| 分不清该用 PowerShell 还是 CMD | 只是窗口名字不同 | ① 开始菜单搜索 PowerShell ② 认准「Windows PowerShell」 ③ 直接用它 | 本手册一律用 PowerShell；命令 `cd`、`dir` 在 CMD 里也能用，但以 PowerShell 为准 |

## 动手练习

1. **找到自己的位置**：打开命令行，用 `pwd` 看当前在哪个文件夹，再用 `dir`（Windows）或 `ls`（macOS）看看里面有哪些文件。目标是：能说出「我现在在哪个文件夹」。
2. **进出文件夹**：在命令行里输入 `mkdir kurumi-test` 新建一个文件夹，用 `cd kurumi-test` 进去，再用 `cd ..` 退出来。重复两次，直到不用想就能做对。
3. **让 Node 打个招呼**：在任意文件夹里运行下面这行命令，让屏幕打印出「你好，Node」；然后把 `node -v` 的版本号记在备忘录里。

```bash
node -e "console.log('你好，Node')"
```

> 提示：如果第 3 题报错，回到第 3.3 节重新验证 `node -v`；如果提示「找不到命令」，说明 Node.js 还没装好或命令行没有重开。

## 本章小结

- 文件装内容，文件夹装文件；路径是「从项目文件夹出发找到某个文件」的写法。
- 扩展名表示文件类型：`.html` 是网页，`.json` 是配置，`.js` 是脚本。
- 命令行是一个用文字下命令的窗口；Windows 用 PowerShell，macOS 用「终端」。
- 三个最常用的命令：`pwd` 看位置，`dir` / `ls` 看内容，`cd` 进入文件夹、`cd ..` 退回上一级。
- Node.js 是运行本项目本地服务器的程序，npm 随它一起装好，不需要单独装。
- 安装 Node.js 选官网 LTS 版；装完必须重开命令行，再用 `node -v` / `npm -v` 验证。
- 本项目要求 Node.js **`>= 13.14.0`**，官网 LTS 版本远高于这个要求。
- 改配置会用到的 `config/app.json` 是 JSON 格式：英文双引号、英文逗号、不能写注释。
