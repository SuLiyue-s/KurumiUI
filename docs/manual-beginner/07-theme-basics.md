# 07 · 配色与主题

> 适用版本：KurumiUI v1.4.4 ｜ 难度：⭐ 入门 ｜ 前置章节：[06-form-basics.md](06-form-basics.md) ｜ 阅读时长：约 30 分钟

## 本章目标

- 能用自己的话说明「主题」是什么，以及它为什么不改变界面结构、只改变颜色。
- 会三种切换主题的方法：点菜单底部的按钮、在配置里写动作、在浏览器控制台里敲一行命令。
- 能看懂 `src/themes.json` 里的一套主题，并把主色改成自己喜欢的颜色。
- 能查到常用配色变量的名字和默认值，知道改一个变量会影响界面的哪些地方。
- 会给自己配一张头像，会调整「选择主题」弹窗的样子。

## 1. 主题是什么

一句话：**主题就是一套「颜色名字表」**。

界面上的颜色不是直接写死的。框架给每种用途起了一个变量名，比如「主强调色」叫 `--kui-accent`，「正文文字」叫 `--kui-text-1`。按钮、进度条、选中的标签页都去引用这些名字；至于「主强调色今天是什么颜色」，由主题来决定。

所以换主题只换颜色、边框、阴影、字体这些「皮肤」——按钮还是那个位置的按钮，菜单还是那么宽，页面结构一点没动。这就是为什么切换主题时界面会「变个颜色」，却不会「变个样子」。

KurumiUI 自带 **6 套主题**，都写在 `src/themes.json` 里。每套主题正好包含 **64 个 `--kui-*` 变量**。名字和风格如下（以 `src/themes.json` 实际内容为准）：

| 主题 id | 显示名称 | 明暗 | 风格 | 什么时候选它 |
| --- | --- | --- | --- | --- |
| `kurumi` | 绯红刻刻帝 | 深色 | 暗夜玻璃 × 绯红 × 金黄，带血月与罗马数字表盘 | 默认主题，喜欢强烈、有戏剧感就选它 |
| `kurumi-angel` | 白羽灵装 | 浅色 | 奶白与淡金打底，浅绯作点睛，白羽飘落 | 白天或明亮的房间，想要干净清爽 |
| `starry` | 星夜观测 | 深色 | 深空蓝紫的穹顶，星点与星辉青交织 | 长时间阅读、看数据，想要冷静 |
| `sakura` | 樱雾通灵 | 深色 | 樱粉与灰紫的薄雾，玫瑰金作饰，樱瓣飘落 | 柔和一点，但保留一点哥特轮廓 |
| `abyss` | 深渊刻印 | 深色 | 墨绿黑与青铜的刻印空间，毒绿只出现在细线上 | 想要极暗、低刺激的界面 |
| `dawn` | 黎明绯光 | 浅色 | 暖白与暖金，绯红作地平线，像清晨第一道光 | 想要明亮但不刺眼 |

> 界面上会看到「灵装」这个词，把它理解成「皮肤」就行，「切换灵装主题」就是「切换主题」。

## 2. 三种切换主题的方式

### 2.1 方式一：点菜单底部的按钮

看左侧菜单的最下方，有一个「切换灵装主题」按钮，前面带一个调色板图标。点它。

**你会看到**：中间弹出一个「选择灵装主题」窗口。窗口里一张张卡片，每张卡片写着主题名、主题 id、一句风格说明，还有几个颜色圆点——那就是这套主题的代表色。

再点其中一张卡片。**你会看到**：窗口关闭，从菜单到按钮、从文字到背景，整个界面立刻换色；卡片在你点之前会有一圈高亮，告诉你现在用的是哪一套。

刷新一次页面，**你会发现**：还是刚才选的那一套。因为它被自动存在了浏览器的 **localStorage**（浏览器自带的一个小仓库，用来记东西）里，记的名字叫 `kui-theme`。

### 2.2 方式二：在配置里写「动作」

「动作」（英文 action）是框架提前起好名字的一段操作。你在配置里写名字，框架就会去执行它。主题相关最常用的动作有四个：

| 动作名 | 作用 |
| --- | --- |
| `theme.picker` | 打开「选择灵装主题」弹窗（菜单底部那个按钮用的就是它） |
| `theme.next` | 按 `src/themes.json` 里的顺序，切到下一套 |
| `theme.prev` | 切到上一套 |
| `theme.apply` | 切到指定的那一套，具体哪一套写在 `params.id` 里 |

**改哪里**：`config/app.json` → `menu.props.footer.actions` 数组。这个数组就是菜单底部的按钮区，里面已经有一个「切换灵装主题」按钮。我们照着它的样子再加一个「下一套主题」按钮。

**改成什么**：在 `actions` 数组里，紧跟在原来那个按钮后面加一个逗号，再粘贴这段：

```json
{
  "type": "button",
  "props": {
    "text": "下一套主题",
    "icon": "palette",
    "size": "sm",
    "variant": "ghost",
    "block": true
  },
  "on": {
    "click": {
      "action": "theme.next"
    }
  }
}
```

**怎么保存生效**：保存文件 → 刷新浏览器。

**你会看到**：菜单底部多出一个「下一套主题」按钮。点一下，界面切到下一套主题；再点一下，再下一套；点到最后一套会回到第一套。刷新后还是最后点出来的那一套。

如果想让某个按钮直接切到指定主题，把 `action` 换成 `theme.apply`，再在 `on.click` 里加 `"params": {"id": "starry"}`。这样点一下就会直达「星夜观测」；`id` 必须和 `src/themes.json` 里的主题 id 一模一样。

### 2.3 方式三：在浏览器控制台里直接问

按 F12 打开开发者工具，切到 **Console（控制台）** 面板。在光标处一行一行输入，每行按回车：

```js
KUI.theme.list()
KUI.theme.apply('starry')
KUI.theme.currentId()
```

**你会看到**：

```text
(6) [{…}, {…}, {…}, {…}, {…}, {…}]        ← 第一行：6 套主题的完整数据
{id: 'starry', name: '星夜观测', …}         ← 第二行：返回被切换到的主题对象
'starry'                                    ← 第三行：确认当前主题 id
```

再敲一行，看看它有没有被记住：

```js
localStorage.getItem('kui-theme')
```

返回值是 `'starry'`，说明保存成功；刷新页面依然是星夜观测。这里改的只是「你这台电脑的这个浏览器」，想把默认主题改成别的，要改配置，见第 7 节的 `theme.default`。

## 3. 看懂 src/themes.json

主题配置就是 `src/themes.json` 这个文件。JSON 就是「用 `{}` 和 `[]` 装数据」的纯文本，三条铁律：**键和值都有双引号、不能写注释、最后一项后面不能多逗号**。写错一个字符，整个文件就读取失败。

文件的最外层只有三样东西：

| 字段 | 作用 |
| --- | --- |
| `default` | 默认主题 id，第一次打开页面时用它 |
| `version` | 文件版本号，写的是 `1.0`，一般不用改 |
| `themes` | 数组，里面一项就是一套主题，共 6 项 |

每套主题里又有这些字段：

| 字段 | 作用 |
| --- | --- |
| `id` | 唯一名字，切换主题、写动作时用它 |
| `name` | 中文显示名，弹窗卡片上显示 |
| `desc` | 一句话风格说明，弹窗里显示 |
| `scheme` | 明暗：`dark` 深色 / `light` 浅色，决定浏览器原生控件用深色还是浅色 |
| `tokens` | 真正的颜色表，64 个 `--kui-*` 变量的取值 |
| `art` | 背景装饰层（血月、星点、樱瓣这些），不影响配色，暂时不用管 |
| `preview` | 弹窗卡片小色块用的三种颜色，只是展示用 |

把 `themes` 数组的第一项（也就是默认的 `kurumi`）简化一下，长这样：

```json
{
  "id": "kurumi",
  "name": "绯红刻刻帝",
  "desc": "默认主题：暗夜玻璃 × 绯红 × 金色刻刻帝。",
  "scheme": "dark",
  "tokens": {
    "--kui-bg-0": "#08050a",
    "--kui-bg-1": "#0d080f",
    "--kui-text-1": "#f4eef3",
    "--kui-text-2": "#bfaebd",
    "--kui-accent": "#c8102e",
    "--kui-accent-hover": "#e22040",
    "--kui-accent-2": "#d4af37",
    "--kui-success": "#57b98c",
    "--kui-warning": "#e0a63c",
    "--kui-danger": "#e33b4e"
  }
}
```

真实文件里 `tokens` 有 64 项，这里只摘了 10 项。看懂这 12 项的名字规律，剩下的也能猜个八九不离十：

- `--kui-bg-2` 这类是**背景色**，数字越大越亮（深色主题里）。
- `--kui-text-1` 这类是**文字色**，数字越大越不显眼：`text-1` 正文、`text-2` 说明文字、`text-3` 更弱。
- `--kui-accent` 是**主强调色**，`--kui-accent-2` 是次强调色，`--kui-accent-hover` 是鼠标移上去时的颜色。
- `--kui-success` / `--kui-warning` / `--kui-danger` 是**语义色**：成功、警告、危险。

## 4. 改主色：让按钮、高亮、进度条一起变色

目标：把默认主题的绯红换成你自己喜欢的颜色，并且让界面里所有用到主色的地方一起变。

### 第 1 步：改哪里

`src/themes.json` → `themes` 数组里 `id` 为 `"kurumi"` 的那一项 → `tokens` 下面的 `"--kui-accent"`。

### 第 2 步：改成什么

改前（片段）：

```json
{
  "id": "kurumi",
  "tokens": {
    "--kui-accent": "#c8102e"
  }
}
```

改后（片段，这里换成蓝色）：

```json
{
  "id": "kurumi",
  "tokens": {
    "--kui-accent": "#3b82f6"
  }
}
```

> 上面只是「片段」，真实文件里这一项还有 `name`、`desc`、`scheme` 和其余 63 个 token，别删掉。

### 第 3 步：保存并更新配置包

保存文件，然后在项目文件夹里打开命令行，运行：

```bash
npm run build:config
```

**为什么改了 JSON 还要跑这个命令？** 因为直接双击 `index.html` 打开时，浏览器出于安全限制读不了本地 JSON，只能读一份提前打包好的配置包 `config/bundle.js`；而用 `npm start` 时页面读的是最新的 JSON 文件。`npm run build:config` 就是重新打包配置包，所以改完跑一次再刷新，两种打开方式都不会出现「明明改了却没生效」。

> 换句话说：**用 `npm start` 时，改完 `themes.json` 直接刷新就生效**；只有 `file://` 双击、或把站点部署成“只上传 `config/bundle.js`”时，才**必须**跑 `npm run build:config`。判断规则见 [04-config-ui.md](04-config-ui.md) 第 9 节。

### 第 4 步：你会看到

主按钮（比如「恢复父级主题」这种实心按钮）从绯红变成蓝色；顶部标签栏当前标签页的高亮线、输入框点进去时的聚焦边框、进度条的填充部分、链接鼠标移上去的颜色，也一起变蓝。

一句话：**凡是原来「绯红」的位置，现在都是你选的颜色**。

### 再试四个常用的

同样在 `kurumi` 的 `tokens` 里，把这四个值一起改掉，你就能得到一套「完全不像默认主题」的配色：

```json
{
  "tokens": {
    "--kui-accent": "#3b82f6",
    "--kui-accent-2": "#22c55e",
    "--kui-bg-1": "#101820",
    "--kui-text-2": "#9fb3c8"
  }
}
```

| 变量 | 改它影响什么 |
| --- | --- |
| `--kui-accent-2` | 次强调色：品牌徽记、装饰线、金色点缀 |
| `--kui-bg-1` | 面板背景：菜单、标签栏、卡片、弹窗底色 |
| `--kui-text-2` | 次要文字：说明、辅助信息 |

> 只改 `kurumi` 不影响另外几套；想让「白羽灵装」也用新主色，要去它那一项改。

**改完没变化？按顺序查这四步**：① 有没有刷新；② 有没有跑 `npm run build:config` 再刷新；③ 控制台敲 `KUI.theme.currentId()` 看当前是不是你改的那套；④ 变量名有没有拼错。

## 5. 常用配色变量速查表

不用背，用到再查。默认值来自 `src/styles/base.css` 顶部的 `:root` 区（没套用主题时的兜底值，和默认主题 `kurumi` 一致）。

| 变量名 | 作用 | 默认值 | 影响哪里 |
| --- | --- | --- | --- |
| `--kui-accent` | 主强调色 | `#c8102e` | 主按钮、选中项、进度条、聚焦边框 |
| `--kui-accent-2` | 次强调色（金） | `#d4af37` | 品牌徽记、装饰线、金色点缀 |
| `--kui-bg-0` | 最深的背景 | `#08050a` | 页面最底层、内容区底色 |
| `--kui-bg-1` | 面板背景 | `#0d080f` | 菜单、标签栏、卡片、弹窗底 |
| `--kui-bg-2` | 次一级背景 | `#130d17` | 悬浮面板、下拉框 |
| `--kui-text-1` | 正文文字 | `#f4eef3` | 标题、正文 |
| `--kui-text-2` | 次要文字 | `#bfaebd` | 说明、辅助信息 |
| `--kui-text-3` | 弱化文字 | `#85748a` | 占位符、禁用说明 |
| `--kui-border` | 边框线 | `rgba(244, 238, 243, 0.1)` | 卡片和控件的边框、分割线 |
| `--kui-radius-md` | 中等圆角 | `6px` | 按钮、输入框、卡片的圆角 |
| `--kui-shadow-2` | 中等阴影 | `0 10px 28px rgba(0, 0, 0, 0.5)` | 弹窗、悬浮卡片的投影 |
| `--kui-font-family` | 正文字体 | 中文系统字体栈 | 全站正文的字体 |
| `--kui-font-mono` | 等宽字体 | `Cascadia Mono`、`Consolas` 等 | 代码、id、数字 |
| `--kui-success` | 成功色 | `#57b98c` | 成功提示、通过状态 |
| `--kui-warning` | 警告色 | `#e0a63c` | 警告提示、注意事项 |
| `--kui-danger` | 危险色 | `#e33b4e` | 删除、错误提示、危险按钮 |

> 先记住三个就够用：**`--kui-accent` 主色、`--kui-bg-1` 面板底、`--kui-text-1` 正文**。

## 6. 设置自己的头像

头像通常出现在右上角或菜单底部。它由 `config/app.json` 的 `avatar` 段控制。

**改哪里**：`config/app.json` → `avatar`。

**改成什么**：把下面这段替换进去（字段含义见后表）：

```json
{
  "avatar": {
    "url": "avatar.png",
    "editable": true,
    "persist": true,
    "size": 48,
    "shape": "circle",
    "alt": "我的头像",
    "frame": {
      "enabled": true,
      "style": "clock-gear",
      "showTicks": true,
      "showRoman": false,
      "showHands": true,
      "animated": true,
      "spinDuration": 48
    }
  }
}
```

| 字段 | 作用 |
| --- | --- |
| `url` | 图片地址。可以写相对路径（相对 `index.html`）、`https://…` 网址，或者 `data:image/…` 这种把图片内容直接写进配置的格式 |
| `editable` | `true` 时点头像可以打开「更换头像」窗口 |
| `persist` | `true` 时把用户换过的头像记在浏览器里，刷新不丢 |
| `size` | 头像直径，单位像素，默认 `42` |
| `shape` | `circle` 圆形 / `square` 方形 |
| `frame.enabled` | 是否显示头像外圈装饰 |
| `frame.style` | 装饰样式，目前只有 `clock-gear`（齿轮表盘） |
| `frame.showTicks` | 是否画刻度 |
| `frame.showRoman` | 是否用罗马数字（默认关闭，小尺寸下容易糊） |
| `frame.showHands` | 是否画指针 |
| `frame.animated` | 是否让外圈缓慢转动 |
| `frame.spinDuration` | 转一圈的秒数：正数正转、负数反转、`0` 停转 |

**怎么保存生效**：保存文件 → 刷新浏览器。

**你会看到**：头像从默认的时钟图标变成你的图片，外圈有一圈齿轮和指针在慢慢转。点一下头像，会弹出「更换头像」窗口，可以填图片地址，也可以清除恢复默认图标。

> 最快做法：把图片改名为 `avatar.png` 放到 `index.html` 旁边，`url` 就写 `"avatar.png"`，不用打开发服务器也不受网络影响。

## 7. 改造主题选择弹窗

「选择灵装主题」弹窗也可以调。**改哪里**：`config/app.json` → `theme` → `picker`。

**改成什么**：比如把三列改成两列，并换掉标题和副标题：

```json
{
  "theme": {
    "default": "kurumi",
    "storageKey": "kui-theme",
    "picker": {
      "title": "挑一套灵装",
      "desc": "点一下即时预览，选错可以再换",
      "columns": 2,
      "showPreview": true,
      "showScheme": true,
      "maskClosable": true
    }
  }
}
```

| 字段 | 作用 |
| --- | --- |
| `title` | 弹窗标题，默认「选择灵装主题」 |
| `desc` | 弹窗副标题，用于一句话说明 |
| `columns` | 每行放几张卡片，默认 `3`；填 1~6 之间的整数，超出范围会自动夹到 1 或 6 |
| `showPreview` | 是否显示每套主题的颜色预览色块 |
| `showScheme` | 是否显示「深色 / 浅色」标记 |
| `maskClosable` | 点弹窗外面那层灰色遮罩时，是否关闭弹窗 |

**怎么保存生效**：保存文件 → 刷新浏览器 → 点菜单底部的「切换灵装主题」。

**你会看到**：弹窗标题变成「挑一套灵装」，副标题变成你写的那句；卡片从每行 3 张变成每行 2 张，卡片本身变宽了。

另外两个顺手的开关也在这个段里：`theme.default` 是默认主题 id（第一次打开的人用它），`theme.visible` 是数组，只写想保留的主题 id，弹窗就只显示那几套。

例如只想保留两套：把 `theme.visible` 写成 `["kurumi", "starry"]`。

## 动手练习

1. **把主色换成你喜欢的颜色**：改 `src/themes.json` 里 `kurumi` 的 `"--kui-accent"` → 跑 `npm run build:config` → 刷新。验证：主按钮和进度条变色，控制台 `KUI.theme.currentId()` 仍返回 `"kurumi"`。
2. **让弹窗只显示三套主题**：改 `config/app.json` 的 `theme.visible`，只留三个 id。验证：打开「切换灵装主题」，数一数卡片是不是三张。
3. **把主题弹窗改成四列**：改 `theme.picker.columns` 为 `4`。验证：窗口里每行四张卡片；再把值改成 `9` 看看会不会被自动夹住。
4. **换一张自己的头像**：把图片放到 `index.html` 旁边，改 `avatar.url`。验证：刷新后头像变化，点一下能打开「更换头像」窗口。
5. **给菜单底部加一个「上一套主题」按钮**：在 `menu.props.footer.actions` 里加一个按钮，`action` 写 `theme.prev`。验证：点一下切回上一套，刷新后仍然保持。

## 本章小结

- 主题就是一套 `--kui-*` 变量的取值，只换颜色皮肤、不改界面结构；自带 6 套，每套 64 个变量，都在 `src/themes.json` 的 `themes` 数组里。
- 切换主题有三种办法：菜单底部按钮（`theme.picker`）、配置里写动作（`theme.next` / `theme.prev` / `theme.apply`）、控制台 `KUI.theme.apply()`。
- 选择会自动存在浏览器的 localStorage 里，键名是 `kui-theme`，刷新仍然生效。
- 改颜色只动 `src/themes.json` 的 `tokens`；改完跑一次 `npm run build:config` 再刷新最稳。
- 最常用的三个变量：`--kui-accent` 主色、`--kui-bg-1` 面板底、`--kui-text-1` 正文。
- 头像在 `config/app.json` 的 `avatar` 段，弹窗样式在 `theme.picker` 段，两者都不用改代码。
