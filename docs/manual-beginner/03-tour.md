# 03 · 认识界面

> 适用版本：KurumiUI v1.4.4 ｜ 难度：⭐ 入门 ｜ 前置章节：[02-first-run.md](02-first-run.md) ｜ 阅读时长：约 18 分钟

## 本章目标

- 能指着屏幕说出 5 个区域：顶部导航、左侧菜单、标签栏、内容区、头像。
- 能查到每个区域由哪个文件、哪个字段控制。
- 亲手完成 6 个体验：切主题、开标签、关标签、设置弹窗、换头像、诊断面板。
- 会用 `F12` 看懂 Elements、Console、Network 三个面板。
- 遇到「点了没反应」时知道第一步查哪里。

## 0. 开始前

本章只动鼠标键盘，**不改文件**。先按 [02-first-run.md](02-first-run.md) 跑起来：`npm start`，浏览器打开 **http://127.0.0.1:8080** 。

📌 本章请用 `npm start` 方式（网址以 `http://127.0.0.1` 开头），第 4 节要在 Network 面板看配置请求；双击 `index.html`（`file://`）也能看界面，但配置读取方式不同。

## 1. 界面地图：先认清 5 个区域

### 1.1 分区图

```text
+----------------------------------------------------------------------+
| (1) 顶部导航   [=] <- -> [R] [F]   KurumiUI > ...   [?] [B]8 [S] [T] |
+------------------+---------------------------------------------------+
| (2) 左侧菜单      | (3) 标签栏                                        |
| +--------------+ | +--------------+------------------+-------------+ |
| | (5) 头像      | | | * KurumiUI   | 未保存数据验证 X | 主题灵装 X  | |
| | KurumiUI     | | +--------------+------------------+-------------+ |
| | KUI - 灵装回路 | +--------------------------------------------------+
| |              | | (4) 内容区                                       |
| | 时间中枢      | |   每个标签对应一个页面，显示在 iframe 里            |
| |  > 总览       | |                                                   |
| |  > 业务结界   | |        pages/home.html（刻刻帝终端首页）           |
| | 灵装回路      | |                                                   |
| | 观测回廊      | |                                                   |
| | 刻印结界      | |                                                   |
| | [切换灵装主题] | |                                                   |
+------------------+---------------------------------------------------+
```

图例：`[=]` 收起菜单、`<- ->` 后退/前进、`[R]` 刷新、`[F]` 全屏、`[?]` 检索、`[B]` 提醒、`[S]` 设置、`[T]` 主题。图标以屏幕为准，悬停有中文提示。

### 1.2 五个区域与启动屏

刷新后最先出现**启动屏**：深色背景、时钟图案、标题 `KurumiUI`、小字和进度条；加载慢时按 `config/app.json` 的 `boot.stages` 依次显示 4 句话（正在加载界面配置…→正在应用界面风格…→正在构建界面…→结界已就绪），通常一闪而过，随即进入主界面。定制看 [07-theme-basics.md](07-theme-basics.md)。

**① 顶部导航**：左边按钮（收起菜单、后退、前进、刷新、全屏）；中间**面包屑**显示当前位置「刻刻帝终端 › 灵装表单」；右边 4 个动作：检索、提醒（角标 8）、设置、主题。由 `menunav` 段控制。

**② 左侧菜单**：顶部品牌区（头像 + 应用名「刻刻帝终端」+ 副标题）；中间分组条目（时间中枢、灵装回路、观测回廊、刻印结界），可带徽章与悬浮提示；底部页脚与「切换灵装主题」。由 `menu` 段控制。

**③ 标签栏**：每个页面一个标签。最左固定首页「刻刻帝终端」（不能关），默认还开「未保存数据验证」「主题灵装」；其他标签有 `✕` 和右键菜单。最多 24 个（`maxTabs`），本版本不支持拖动排序（`drag` 为 `false`）。由 `tabs` 段控制。

**④ 内容区**：显示当前标签的页面。每个页面是独立小网页，用 **iframe** 嵌在这里；切标签不销毁（`keepAlive` 默认 `true`），输入内容切走再回来还在。默认首页 `pages/home.html`，由 `app.home`、`tabs.props.home` 控制。

**⑤ 头像**：菜单品牌区左边圆形头像，外圈是可转动的时钟齿轮；默认内置红色时钟，悬停「点击设置头像」，点它可换（见 3.5）。由 `avatar` 段控制。

**⑥ 主题按钮**：顶部导航右侧调色盘 `[T]`，或菜单底部「切换灵装主题」，作用相同（见 3.1）。

**⑦ 浮层**：启动屏、设置/主题/换头像弹窗、提醒气泡、诊断面板；临时盖在界面上，不属于固定区域。

## 2. 每个区域由哪个文件控制

界面由几个**配置文件**决定。JSON 是写配置的文本格式，形如 `{ "键": "值" }`。三个最重要的文件：

| 文件 | 管什么 | 一句话记忆 |
| --- | --- | --- |
| `config/app.json` | 界面结构与位置：标题、菜单、标签页、头像、主题、布局 | 界面的总开关 |
| `config/text.json` | 界面上的文字：按钮字、提示语、空状态文案 | 界面说什么话 |
| `src/themes.json` | 配色：6 套主题的颜色 | 界面穿什么衣服 |

把区域和配置对上，想改先查表：

| 你看到的区域 | 文件 | 关键字段 | 想改去看 |
| --- | --- | --- | --- |
| 应用名 / 副标题 / 浏览器标题 | `config/app.json` | `app.title`、`app.subtitle`、`app.documentTitle` | [04-config-ui.md](04-config-ui.md) |
| 顶部导航按钮显隐、面包屑 | `config/app.json` | `menunav.props.showCollapse`、`breadcrumb` 等 | [08-components.md](../manual/08-components.md) |
| 顶部导航右侧 4 个动作按钮 | `config/app.json` | `menunav.props.actions`（`settings.open`、`theme.picker`） | [04-config-ui.md](04-config-ui.md) |
| 左侧菜单分组、条目、徽章 | `config/app.json` | `menu.props.items`（`group`/`item`/`divider`） | [04-config-ui.md](04-config-ui.md) |
| 菜单页脚与按钮 | `config/app.json` | `menu.props.footer` | [04-config-ui.md](04-config-ui.md) |
| 头像、齿轮外框、换头像弹窗 | `config/app.json` | `avatar.url`、`editable`、`size`、`frame` | [04-config-ui.md](04-config-ui.md) |
| 标签栏首页、默认标签、能否关闭 | `config/app.json` | `tabs.props.home`、`initial`、`closable`、`maxTabs` | [04-config-ui.md](04-config-ui.md) |
| 内容区默认页面 | `config/app.json` | `app.home`、`tabs.props.home.url` | [05-new-page.md](05-new-page.md) |
| 界面上所有文字 | `config/text.json` | 按组：`app`、`menu`、`tabs`、`dialog` 等 | [04-config-ui.md](04-config-ui.md) |
| 6 套主题的颜色 | `src/themes.json` | `themes[].tokens` 的 `--kui-*` 变量 | [07-theme-basics.md](07-theme-basics.md) |
| 设置弹窗内容 | `config/app.json` | `dialogs.settings` | [04-config-ui.md](04-config-ui.md) |

一段真实配置（`config/app.json` 节选），决定应用名和头像：

```json
{
  "app": { "title": "刻刻帝终端", "subtitle": "灵装回路 · 时间结界控制台" },
  "menu": { "props": { "brand": { "title": "刻刻帝终端", "subtitle": "KurumiUI · 灵装回路" } } },
  "avatar": { "editable": true, "size": 42, "shape": "circle" }
}
```

⚠️ 改 JSON 最常见错误：少/多逗号、中文引号 `“”`。改坏会启动失败，看第 4.2 节。

## 3. 动手点一点：6 个体验

### 3.1 切主题

**点哪里**：顶部导航最右调色盘 `[T]`；或菜单底部「切换灵装主题」。

**看到什么**：弹出「选择灵装主题」，6 张卡片：绯红刻刻帝（默认）、白羽灵装、星夜观测、樱雾通灵、深渊刻印、黎明绯光。点一张，菜单、导航、标签栏、已开页面同时换色，窗口关闭。

**受什么控制**：`theme` 段决定列哪几套（`theme.visible`）、默认哪套（`theme.default`）、弹窗标题（`theme.picker`）；颜色在 `src/themes.json`。选择记在浏览器（存储键 `kui-theme`），刷新不变。

### 3.2 开一个新标签

**点哪里**：左侧菜单「时间中枢」→「业务结界」→「灵装表单」。

**看到什么**：标签栏末尾多出「灵装表单」并选中，内容区出现表单页，面包屑更新。再点同项不会开第二个，而是切到已开的。

**受什么控制**：条目开哪个页面由 `menu.props.items` 的 `target.tab` 决定（`id`、`title`、`url`）；最多开几个由 `tabs.props.maxTabs` 控制。

### 3.3 关掉一个标签

**点哪里**：「未保存数据验证」标签上的 `✕`；或右键标签→「关闭标签」。

**看到什么**：标签消失，自动切到相邻标签。首页「刻刻帝终端」没有 `✕`，被固定住了。

**试试未保存拦截**：在「灵装表单」填几个输入框（别保存）再点 `✕`，会弹「存在未刻印的数据」确认框，点「取消」不关。

**受什么控制**：`tabs.props.closable`、`pinnedClosable`（当前 `false`）、`contextMenu`；确认框文字在 `config/text.json` 的 `tabs` 组。

### 3.4 打开「终端设置」弹窗

**点哪里**：顶部导航右侧齿轮 `[S]`（悬停「终端设置」）。

**看到什么**：弹出「终端设置」：终端名称（必填）、默认主题（6 项）、启动页（7 个页面）、记住上次标签（开关）、界面密度（紧凑/标准/宽松）；底部「取消」「保存设置」。点保存后关闭，右上角提示「设置已应用」。

**受什么控制**：全来自 `dialogs.settings`；入口来自 `menunav.props.actions` 的 `settings.open`。

📌 **保存到哪里去了？** 点「保存设置」后，这些值会写进**当前浏览器的 localStorage**（终端名称 → `kui-shell-name`、默认主题 → `kui-theme`、启动页 → `kui-start-tab`、记住上次标签 → `kui-remember-tab`、界面密度 → `kui-density`），**不会修改 `config/app.json`**。所以终端名称和界面密度会立刻变，主题立即切换；「启动页」和「记住上次标签」要等**下次打开主应用**时才生效。换浏览器、换电脑或清掉浏览器数据，这些设置就回到 `config/app.json` 里的默认值。

> 一句话：**配置 JSON 是“默认值”，界面上保存的是“这台浏览器的偏好”**。想让所有访问者都看到新的默认标题/皮肤，要改配置文件，而不是在界面上保存（详见 [04-config-ui.md](04-config-ui.md) 第 9 节）。

### 3.5 换一个头像

**点哪里**：菜单品牌区的圆形头像（悬停「点击设置头像」）。

**看到什么**：弹出「更换头像」：头像图片地址（可粘贴 `https://` 链接）、预设头像（下拉）、清除自定义头像（开关）。点「应用」立即换，齿轮框保留、颜色跟主题；刷新仍是新头像——存在浏览器本地，没改文件。

**受什么控制**：`avatar` 段：`url`（留空显示时钟图标）、`editable`、`size`（42 像素）、`shape`（`circle`）、`frame`（齿轮刻度/指针/转动）；弹窗文字来自 `avatar.picker`。想恢复默认：再点开，打开「清除自定义头像」再应用。

### 3.6 打开诊断面板（`?kui_debug=1`）

**点哪里**：网址末尾加 `?kui_debug=1`，如 `http://127.0.0.1:8080/?kui_debug=1`。

**看到什么**：右下角出现深色「KurumiUI 诊断 · v1.3.8」面板，有「复制」「收起」，滚动日志记录：版本、浏览器、窗口大小、当前主题、页面报错、超过 120 毫秒的卡顿、输入/焦点/弹窗/iframe 消息计数；最多 260 行。

**受什么控制**：只是网址参数，不改文件；去掉参数即恢复。界面卡或点了没反应时，开它复现一次并把日志复制下来（见 [09-troubleshooting.md](09-troubleshooting.md)）。

## 4. 开发者工具入门（F12）

### 4.1 打开它

Windows/Linux 按 `F12`；macOS 按 `Option + Command + I`；或右键→「检查」。先认三个标签：

- **Elements**：页面骨架。点左上箭头再点界面某块，下面高亮对应代码；改配置没变化时先看这里。
- **Console**：留言板。正常基本空；**红色=出错**，黄色=警告。
- **Network**：所有请求，看每个文件是否加载成功。

### 4.2 Console 红字怎么读

一行红字通常三段：**错误类型 + 说明 + 文件位置**，例如 `Uncaught SyntaxError: Unexpected token } in JSON at position 123`（某个 JSON 多写了 `}`）。常见三类：

| 红字里的词 | 意思 | 先检查 |
| --- | --- | --- |
| `404` / `Failed to load resource` | 没找到文件 | 文件名、路径拼写（对照第 2 节表） |
| `SyntaxError` | JSON 写坏 | 少/多逗号、中文引号 |
| `TypeError` | 值类型不对 | 该写数字/开关处写了文字 |

读法：先看**最上面第一条**（后面常是连锁反应）；点右侧文件名可跳到出错行。

📌 配置改坏时不会白屏，启动屏会变「**界面启动失败**」，给排查建议和「重新加载」按钮（文字来自 `config/text.json` 的 `boot` 组）。

### 4.3 用 Network 看配置请求

1. 开发者工具切到 `Network`。
2. 按 `F5` 刷新（只记录打开面板之后的请求，要先开面板再刷新）。
3. 筛选框输入 `config`，应看到 `config/app.json`、`config/text.json`、`src/themes.json` 三条请求，Status 绿色 `200`（部分演示页还会看到 `config/demos/…`）。
4. 点一条 → 右侧 `Preview` 展开看 JSON，确认改的字段真加载了。

| 现象 | 最可能原因 | 怎么办 |
| --- | --- | --- |
| `404`（红色） | 文件名或路径写错 | 对照第 2 节表检查 |
| 看不到任何请求 | 用的是 `file://` | file:// 从 `config/bundle.js` 读配置，不走网络；改用 `npm start` |
| 改完没变化 | 还开着旧页面 | 保存后 `Ctrl + F5` 强制刷新 |

💡 网速下拉选 `Slow 3G` 再刷新，能看清启动屏 4 个阶段文字；看完切回 `No throttling`。

## 5. 名词卡：6 个词，一句话

| 词 | 一句话解释 |
| --- | --- |
| 菜单 | 左侧那一列导航，可分组、可折叠。 |
| 标签页 | 顶部标签栏里打开着的页面，一个标签对应一个页面。 |
| 面包屑 | 顶部导航中间「刻刻帝终端 › 当前页面」，告诉你现在在哪。 |
| 组件 | 比控件大的一块界面模块（菜单、标签栏、弹窗），框架用 JSON 描述。 |
| 节点 | 配置里描述界面一块的 JSON：`{ "type": "…", "props": { … } }`。 |
| iframe | 网页里再套网页的「窗口」；内容区每个页面都住在 iframe 里，所以切标签不丢数据。 |

更全的词典（20 多个词）见 [README.md](README.md) 的「名词小词典」。

## 动手练习

**练习 1：认清顶部导航的 4 个按钮**

- 要做什么：点开右侧 4 个按钮，记下弹出的窗口和「提醒」的红色数字。
- 怎么验证：能说出「检索、提醒、设置、主题」，角标是 8。
- 提示：设置弹窗叫「终端设置」，主题弹窗叫「选择灵装主题」。

**练习 2：找到「灵装表单」标签页的配置来源**

- 要做什么：打开 `config/app.json` 搜索「灵装表单」，看它打开哪个页面文件。
- 怎么验证：能找到 `pages/form.html`，外层是 `target` → `tab` → `url`。
- 提示：JSON 一层套一层，注意缩进。

**练习 3：换主题、刷新、再换回来**

- 要做什么：切到「白羽灵装」，刷新确认仍是它，再切回「绯红刻刻帝」。
- 怎么验证：刷新后没退回默认，说明浏览器记住了。
- 提示：想想「记住」存在哪里，答案在 3.1。

## 本章小结

- 主界面 5 区域：顶部导航、左侧菜单、标签栏、内容区、头像；主题按钮在两处。
- 启动屏是刷新后最先看到的加载动画，由 `boot` 控制，通常一闪而过。
- `config/app.json` 管界面，`config/text.json` 管文字，`src/themes.json` 管颜色。
- 顶部导航右侧 4 按钮：检索、提醒、设置、主题；设置弹窗在 `dialogs.settings`。
- 一个标签对应一个页面，首页固定不可关；切标签不销毁页面，未保存内容会拦截关闭。
- 按 `F12`：Console 看红字、Network 看配置是否 `200`，是排查第一步。
