# 07 · 风格方案（6 套可切换主题）

> 对应需求第 1 条：**科技未来 + 动漫（时崎狂三）风，不是赛博风**；并"多给几套风格样式用来挑选"。
> 框架的**结构与控件只有一套**，风格全部靠 CSS Token 切换 —— 所以在任何一套主题下，控件、弹层、日历、滚动条的材质与手感都是同一套设计语言，只是配色与装饰层不同。

## 一、设计基线（为什么不是赛博风）

| 要素 | 本项目（科技未来 + 动漫哥特） | 赛博朋克（明确排除） |
| --- | --- | --- |
| 主色 | 绯红 `#c8102e` + 暗夜紫黑 `#08050a` + 古金 `#d4af37` | 荧光青 / 洋红 / 荧光绿大面积撞色 |
| 光 | **内发光**、细描边、玻璃反光、低强度外发光 | 强霓虹管、大面积 bloom、扫描线故障 |
| 质感 | 暗夜玻璃 + 细网格 HUD + 斜切角 + 罗马数字表盘 | glitch、噪点故障、全息投影 |
| 装饰 | 刻刻帝时钟、血月、羽毛、齿轮、和风纹样 | 电路板线、乱码、RGB 分离 |
| 动效 | 120 / 200 / 320ms，缓入缓出，克制 | 高频闪烁、抖动、故障跳变 |
| 字体 | 思源黑 / 苹方 / 微软雅黑，字距略松 | 像素字 / 等宽科幻字 |

所有颜色、阴影、发光、圆角、动效都来自 `--kui-*` token；主题只覆盖 token + 装饰层，**不写主题专属选择器**，所以切主题不会出现"某个控件忘了改颜色"。

每套主题固定覆盖 **64 个外观类 token**（背景 5 级、文字 3 级、强调色 3 组、语义色 4 个、语义前景色 `--kui-on-*` 4 个、边框/分隔/遮罩、阴影/发光/高光、控件 13 项、滚动条 3 项、弹层/选项 5 项、日历 4 项、玻璃 4 项）；
**尺寸、字体、圆角、动效共 30 个 token 不随主题变化**，所以切换主题不会跳动布局、不会变字号。

## 三、怎么切换

### 1）界面里切（给最终用户）

- 顶部导航最右的 **"主题"** 按钮 → 打开主题选择弹窗（弹窗也是独立 iframe，卡片实时预览）；
- 左侧菜单底部 **"切换灵装主题"**；
- 设置弹窗里的 **"默认主题"** 下拉（会持久化）。

切换即时生效并写入 `localStorage`（key 默认 `kui-theme`），**所有 iframe（业务页、弹窗）同步收到新 token**。

### 2）URL 参数切（给演示/截图）

```
http://127.0.0.1:8080/?kuiTheme=starry
http://127.0.0.1:8080/?kuiTheme=kurumi-angel
```

优先级：URL `?kuiTheme=` > `localStorage` > `app.json` 的 `theme.default`。

### 3）代码里切

```js
KUI.theme.apply('sakura');        // 指定主题
KUI.theme.next();                 // 下一套
KUI.theme.ids();                  // ['kurumi', 'kurumi-angel', ...]
KUI.theme.list();                 // 含 name/desc/scheme/tokens 的完整列表
```

### 4）改默认风格（只改配置）

`config/app.json`：

```json
{ "theme": { "default": "starry", "storageKey": "kui-theme", "persist": true } }
```

### 5）只让用户看到其中几套

```json
{ "theme": { "visible": ["kurumi", "starry", "dawn"] } }
```

## 四、想自己加一套风格

只改 `src/themes.json`，**不动任何代码**：

```json
{
  "id": "my-style",
  "name": "自定义风格",
  "desc": "一句话说明",
  "scheme": "dark",
  "tokens": {
    "--kui-bg-0": "#05060a",
    "--kui-accent": "#00b3a4",
    "--kui-accent-2": "#e8c07d"
    // 其余 57 个可缺省：缺省项自动继承 base.css 的默认值
  },
  "art": {
    "layers": [
      { "kind": "glow", "x": "78%", "y": "12%", "opacity": 0.22 },
      { "kind": "grid", "opacity": 0.06 }
    ]
  },
  "preview": { "bg": "#05060a", "accent": "#00b3a4", "accent2": "#e8c07d", "text": "#eaf4f2" }
}
```

可选装饰层 `kind`（11 种）：`glow` `grid` `clock` `moon` `rays` `scanline` `stars` `sakura` `feather` `noise` `vignette`，
每种支持 `opacity / x / y / size` 等参数（详见 [`docs/04-theme.md`](./04-theme.md)）。

新增后主题选择弹窗会自动出现这张卡片（不需要改 bootstrap）。

## 五、人工核对清单（换风格后逐项过一遍）

1. 左侧菜单：分组标题、选中态、悬停态、徽标、折叠态图标、底部按钮；
2. 顶部导航：面包屑、历史按钮禁用态、图标按钮悬停、全屏态；
3. 子标签：激活/未激活/悬停/关闭按钮/脏数据圆点/右键菜单；
4. 主体 iframe：页面背景与外壳是否融合（不出现白色块）；
5. 控件：输入框聚焦环、数字框上下箭头、下拉弹层描边与阴影、多选已选 tag、textarea 角标、日历面板、时/分/秒选择列、开关、滑块、评分、颜色块；
6. 弹窗：遮罩浓度、弹窗描边/阴影、按钮主次、输入框、表单标签；
7. 提醒：四类语义色与图标、进度条、堆叠位置；
8. 滚动条：页面、菜单、弹窗内、下拉列表，颜色与轨道一致；
9. 切主题动画（320ms）是否有明显闪烁或残留旧色；
10. 亮色主题（`kurumi-angel` / `dawn`）下，所有文字对比度是否仍然足够。
